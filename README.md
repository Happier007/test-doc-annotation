# Test doc annotation

Тестовое задание. Приложеие для просмотра документа и добавления текстовых аннотаций. Реализовано на angular (22.1.8) без сторонних библиотек.

## Запуск приложения

Требуется Node.js `^22.22.3`, `^24.15.0` или `>=26`.

```bash
npm install
ng serve
```
Откройте `http://localhost:4200/documents/1`.

## Возможности
- загрузка документа по ID из URL;
- просмотр всех страниц документа;
- изменение масштаба с шагом 10%;
- добавление аннотации двойным щелчком по странице;
- перетаскивание и удаление аннотаций;
- вывод документа с аннотациями в консоль по кнопке «Сохранить».

## Плюсы приложения
- не используются сторонние библиотеки;
- аннотации ограничены границами страницы;
- используется строгая типизация, onPush, signals;
- координаты аннотаций хранятся в процентах, поэтому сохраняют положение при изменении масштаба.

## Минусы приложения
- мок содержит только документ 1;
данные сохраняются только в консоль и пропадают после обновления страницы;
- ID аннотаций - это сквозной счётчик для всех страниц документ. После перезагрузки приложения счётчик начинается заново;
- текст готовой аннотации нельзя редактировать;
- перетаскивание аннтоции использует только события мыши и не не поддерживает тач-устройства;
- сохранение только выводит данные в консоль
